# Contribuindo

Use Python 3.12 ou superior. Instale com `pip install -e ".[dev]"`, execute `ruff check .` e `pytest` antes de enviar mudanças. Commits seguem Conventional Commits.

Mantenha domínio, parser, gerador, persistência e UI desacoplados. Mudanças de comportamento devem incluir testes. Pull requests devem descrever motivação, validação e limitações conhecidas.
