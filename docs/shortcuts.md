# Atalhos

| Atalho | Ação |
|---|---|
| `V` | Seleção |
| `L` | Linha |
| `R` | Retângulo |
| `Q` | Quadrado |
| `T` | Triângulo |
| `E` | Círculo / elipse |
| `S` | Estrela |
| `F` | Lápis livre |
| `P` | Polígono |
| `I` | Linha contínua |
| `O` | Contorno fechado |
| `X` | Texto |
| `Delete` | Excluir |
| `Ctrl+Z` | Desfazer |
| `Ctrl+Shift+Z` | Refazer |
| `Ctrl+C` / `Ctrl+V` | Copiar / colar |
| `Ctrl+D` | Duplicar |
| `Ctrl+N` | Novo |
| `Ctrl+O` | Abrir |
| `Ctrl+S` | Salvar |
| `Ctrl+Shift+S` | Salvar como |
| `Ctrl+E` | Exportar Python |
| `Ctrl+0` | Ajustar canvas |

Durante retângulo ou elipse, mantenha `Shift` pressionado para criar quadrado ou círculo. No polígono, use duplo clique ou `Enter` para finalizar e `Esc` para cancelar. Use o botão do meio para pan e a roda para zoom.
